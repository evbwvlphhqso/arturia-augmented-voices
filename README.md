## Overview

Arturia Augmented Voices merges choral and vocal ensemble samples with wavetable synthesis to create everything from realistic choirs to ethereal, processed hybrid vocal pads.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Augmented Voices** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Vocal Samples** | Soprano, alto, tenor, and bass choral ensemble recordings |
| **Wavetable Layer** | Vocal-derived wavetables for hybrid synthesized vocal textures |
| **Vowel Morphing** | Smooth morphing between vowel formants for singing voice effects |
| **FX** | Reverb, chorus, and formant filter built in for complete vocal processing |
